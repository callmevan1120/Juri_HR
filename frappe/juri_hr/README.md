# juri_hr

Custom Frappe app untuk JURI HR — fitur HR unik yang tidak tersedia standar di Frappe HR:

- `Izin Request` (izin dipisah dari cuti, workflow sendiri)
- `Overtime Request`, `WFH Request`, `Shift Swap Request`
- `Attendance Correction`, `Offline Checkin Queue`, `Attendance Scan Log`
- `Dynamic QR Token`, `Employee Face Descriptor`, `Barcode Location`
- `Field Client`, `Visit Evidence`
- `Chat Thread` / `Chat Message`
- Whitelisted API methods yang dipanggil frontend Vue 3

Dokumentasi mapping: `../../REWRITE-MATRIX.md` (relatif dari repo root).
